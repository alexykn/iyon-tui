## Interpretation

- **Defect:** source-confirmed erroneous behavior; scope of demonstrated impact stated.
- **Deviation:** actual mismatch with an unsuperseded intended contract; not necessarily a runtime bug.
- **Risk/open:** plausible concern whose production reachability, intended requirement or safety argument remains incomplete.
- **Evidence gap:** a check/label cannot support the stronger claim made for it.
- **Resolved:** disproved concern or intentionally distinct route, with correction retained.
- No finding below authorizes code changes. A recommendation to document an improvement is not approval of that improvement.
- “Expected” can mean an approved handoff, local documented contract or proposed invariant. These authorities are deliberately distinguished.

## Resolved concerns and deliberately distinct paths

- No second N-API Source payload mutation route; reports10/27 corrected.
- Typed diff lowering to Column explains current state-kind mapping; not a demonstrated mismatch.
- Same-identity slot publication still invokes installation; no proved same-root no-op defect.
- Root body fill normalization is outer-only, not a layout bug.
- Raw page-backed semantic input versus copied TextRun values are different ownership layers, not a universal zero-copy failure.
- Generic test-only App driver is not an alternate production Rust session scheduler.
- Native semantic freeze, frozen physical transfer remainder, and Source seal are different operations.
- Theme `color` default-context variant resolution matches TS behavior; `style` base lookup is distinct.
- Full/row paint paths and direct typed diff/text-stream diff are intentional separate mechanisms; correctness/parity must be evaluated within each contract.
- Exported structural C symbols do not create a production TS transport fallback.
- Type-only exports, private modules, weak handles and nonowning IDs must be evaluated by their actual declaration/lifetime semantics, not their labels.
- Missing native addon does not silently pass tests whose import eagerly requires it; real native ABI Rust unit coverage exists.
- Raw Rust helper trust boundaries, theoretical integer exhaustion and absence of a test do not alone establish reachable bugs.
